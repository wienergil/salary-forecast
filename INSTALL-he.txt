תחזית שכר — התקנה באייפון
================================

האפליקציה היא PWA מקומית. הנתונים נשמרים רק במכשיר, לא בשרת.
כדי להוסיף למסך הבית צריך לפתוח אותה ב-Safari דרך כתובת HTTPS
(לא מקובץ מקומי, ולא מ-Chrome).

פרסום לאתר HTTPS
----------------
צריך חשבון חינמי באחד מהשירותים הבאים, ואז להעלות את תוכן קובץ ה-zip
(עם index.html בתיקייה הראשית):

• Netlify: https://app.netlify.com/drop — גוררים את ה-zip ומקבלים כתובת ‎*.netlify.app
• GitHub Pages: יוצרים מאגר, מעלים את הקבצים, ומפעילים Pages
• Vercel: מעלים את התיקייה בפרויקט סטטי

התקנה באייפון (Safari)
----------------------
1. פתחו את כתובת האתר ב-Safari.
2. לחצו על כפתור השיתוף (הריבוע עם החץ למעלה).
3. גללו ובחרו «הוספה למסך הבית».
4. אם רוצים, שנו את השם ל«תחזית שכר» ואשרו «הוסף».

אחרי ההתקנה האייקון יופיע במסך הבית, והאפליקציה תעבוד גם בלי אינטרנט.
כדי לגבות את הנתונים: «שיתוף / ייצוא» שומר או משתף קובץ JSON.
